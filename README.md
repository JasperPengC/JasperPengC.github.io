# JasperPengC.github.io

此仓库通过 GitHub Pages 托管 PP Clash 官网。站点源码位于 [ppclash-website](https://github.com/JasperPengC/ppclash-website)，发布地址为 <https://jasperpengc.github.io/ppclash/>。

首次启用或更新站点时，在 **Actions → Deploy PPClash website → Run workflow** 手动运行部署工作流。工作流会拉取源码仓库 `main` 分支、构建 VitePress，并将产物发布到 `/ppclash/`。
